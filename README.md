# tlog2chart

Plot EVC tlog (MAVLink telemetry log) data as charts.

## Overview

`tlog2chart` reads `.tlog` files generated by MAVLink-based ground control
stations (Mission Planner, QGroundControl, MAVProxy …) and produces
per-message-type PNG charts for common EVC telemetry fields such as battery
voltage / current, speed, altitude, attitude, and GPS data.

## Installation

```bash
pip install -r requirements.txt
pip install .
```

## Usage

### Command line

```bash
# Plot all default message types into the charts/ directory
tlog2chart flight.tlog

# Choose an output directory
tlog2chart flight.tlog -o my_charts/

# Plot specific message types only
tlog2chart flight.tlog -m VFR_HUD ATTITUDE BATTERY_STATUS

# List available message types in a file
tlog2chart flight.tlog --list-messages

# Also show interactive windows
tlog2chart flight.tlog --show
```

### Python API

```python
from tlog2chart import TlogParser, TlogPlotter

# 1. Parse the tlog file
parser = TlogParser("flight.tlog")
data = parser.parse()

print(parser.available_message_types())  # e.g. ['VFR_HUD', 'ATTITUDE', ...]

# 2. Generate and save charts
plotter = TlogPlotter(data)
plotter.plot(output="charts/")
```

## Default message types

| Message type          | Fields plotted                                        |
|-----------------------|-------------------------------------------------------|
| `BATTERY_STATUS`      | voltage, current, remaining                           |
| `SYS_STATUS`          | voltage, current                                      |
| `VFR_HUD`             | airspeed, ground speed, altitude, throttle, climb rate|
| `ATTITUDE`            | roll, pitch, yaw                                      |
| `GPS_RAW_INT`         | altitude, speed, satellites visible                   |
| `GLOBAL_POSITION_INT` | relative altitude, vx, vy, vz                         |
