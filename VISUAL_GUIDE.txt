Parameter Format Conversion - Visual Guide
===========================================

WHAT WAS BUILT
==============

tlog File
    ↓
    │ Raw parameter lines from header
    │ - Format 1: "2 011001, 3 00, 4 0" (Tykon style)
    │ - Format 2: "1,70.0,2,1111,3,0" (Quantum style)
    │ - Format 3: "101: 10.0 ms = ..." (Doc style)
    │
    ↓
extract_parameter_blocks()
    ↓ List[(section, raw_line)]
    ↓
parse_param_pairs_from_line()
    ↓ List[(param_id, value)]
    │ Automatically detects format!
    │
    ↓
build_param_value_table()
    ↓ List[(section, param_id, value)]
    │ Structured & organized
    │
    ↓
convert_params_to_par_template_format()
    ↓ Formatted String
    │ "General Parameters"
    │ "2\t011001"
    │ "3\t00"
    │ ...
    │ "Match Parameters"
    │ "104\t5000"
    │ ...
    │
    ↓
export_params_to_par_file()
    ↓
    .txt file (par template format)

HOW TO USE IT
=============

Method 1: Export to File
────────────────────────
    from tlog2chart_p3.tlog_reader import load_tlog, export_params_to_par_file

    df, info, params = load_tlog("file.txt")
    export_params_to_par_file("output.txt", params)

    ✓ Creates file with formatted parameters


Method 2: Get as String
───────────────────────
    from tlog2chart_p3.params_desc import build_param_value_table, convert_params_to_par_template_format

    rows = build_param_value_table(params)
    text = convert_params_to_par_template_format(rows)

    ✓ Returns formatted string for display/processing


Method 3: Command Line
──────────────────────
    python tlog2chart_p3/example_param_conversion.py input.txt output.txt

    ✓ Standalone script for batch processing

EXAMPLES
========

Example 1: Simple Export
────────────────────────
from tlog2chart_p3.tlog_reader import load_tlog, export_params_to_par_file

df, info, params = load_tlog("my_tlog.txt")
export_params_to_par_file("my_params.txt", params)


Example 2: Get Formatted String
────────────────────────────────
from tlog2chart_p3.params_desc import build_param_value_table, convert_params_to_par_template_format

rows = build_param_value_table(params)
formatted = convert_params_to_par_template_format(rows)
print(formatted)


Example 3: Batch Export
────────────────────────
import glob
from tlog2chart_p3.tlog_reader import load_tlog, export_params_to_par_file

for tlog_file in glob.glob('*.txt'):
    df, info, params = load_tlog(tlog_file)
    output = tlog_file.replace('.txt', '_params.txt')
    export_params_to_par_file(output, params)


Example 4: Command Line
───────────────────────
python tlog2chart_p3/example_param_conversion.py file.txt output.txt
